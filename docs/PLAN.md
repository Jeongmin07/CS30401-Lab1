- 공통 저장소: `Jeongmin07/CS30401-Lab1`.
- 과제 목표: LEO 위성망에서 TCP의 구체적인 문제를 재현하고 원인을 설명한 뒤, 개선안을 구현/평가한다.
- 2026-10-09에 확인한 `main`의 `fa99ffa6772b1d4d6826b557ad49b74b5b28eb61`에는 `shared-results/` 실험 결과가 올라와 있다. 200초 CUBIC(큐 1,000/100), NewReno(큐 1,000) 결과와 20초 환경 확인 결과이며, 최종 연구 조건을 합의한 것은 아니다. 협업 문서와 GitHub 양식은 PR #2에서 검토 중이고, 공통 분석 도구와 개선 구현은 아직 통합되지 않았다.
- `kim-seongchan/cs30401-2026f-lab1-team05`에는 기존 Docker 실행/기본 테스트 파일과 로컬 검증 기록이 있다. 필요하면 별도 setup PR로 옮긴다. 기존 검증을 이 저장소에서 다시 수행한 것처럼 표시하지 않는다.

## 사용할 공식 환경

- Docker 이미지: `ghcr.io/yeonjong21/cs30401-lab1:2026f-v1`.
- ns-3.48 + 제공된 Hypatia 모듈.
- 제공된 서울-런던 예제 state는 200초, routing step은 100ms다.
- 기본 모델에는 무작위 무선 손실, handover outage, 시간에 따른 링크 용량 변화가 없다. 그런 현상을 연구하려면 모델 추가와 근거가 필요하다.

공식 환경 출처: <https://github.com/Yeonjong21/cs30401-lab1-env>.
