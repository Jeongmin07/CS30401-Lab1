Eligible presumed-loss holes share one short episode deadline, started by the first SACK presumed-loss marking opportunity. The deadline is never refreshed by later SACKs or by moving to another eligible head. Outside-cohort known loss, stock recovery/ECN/RTO, the forecast SACK budget and registration expiry return to normal recovery. This is a bounded hypothesis, not exact packet-arrival prediction or RACK implementation.
